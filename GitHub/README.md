# SoulCam - 灵魂出窍（单人）

按 F6 让视角离开人物，自由飞行；右键选中物体后出现操作轴，右键循环
「移动 → 缩放 → 旋转」，左键拖轴改物体，ESC 退出操控，中键平移视角，WASD 移动。

## 安装

### 方式 A：下载 ZIP

1. 点右上角 `Code` → `Download ZIP`
2. 解压，把解压出的文件夹**重命名为 `soulcam`**
3. 放到：

```
...\GarrysMod\garrysmod\addons\soulcam
```

确认路径是 `addons\soulcam\addon.json`，不要多套一层文件夹。

### 方式 B：git clone

```bat
cd "...\GarrysMod\garrysmod\addons"
git clone https://github.com/你的用户名/仓库名.git soulcam
```

进游戏读图即可，无需订阅、无需改任何原文件。

## 按键

| 操作 | 按键 |
|---|---|
| 开关灵魂出窍 | `F6`（也可 `bind 键位 soulcam_toggle`） |
| 隐藏/显示 UI | `F9`（F7 被 quick save 占用；也可 `bind 键位 soulcam_ui`） |
| 控制人物 / 视角 | `Z` 切换（镜头锁定，人物可动；再按恢复镜头控制） |
| 移动相机 | `W A S D`，`Shift` 加速，`Alt` 减速 |
| 上下移动相机 | `Space` / `Ctrl` |
| 选中物体 | 屏幕中心对准物体，右键（打开物体菜单） |
| 进入操作轴 | 菜单里点「1. 操作轴」 |
| 切换操作轴 | 操作轴模式下再次右键：移动 → 缩放 → 旋转 → 移动 |
| 拖动操作轴 | 左键按住轴拖动（此时出现鼠标指针，相机锁定） |
| 返回物体菜单 | 轴模式下按鼠标中键 |
| 退出物体操控 | `ESC`（再按一次退出灵魂出窍） |
| 撤销 | 沙盒默认 `Ctrl+Z` |
| 调灵敏度 | 物体菜单里的「镜头灵敏度」数字框（0~2） |
| 查未绑定键位 | 控制台 `soulcam_keys` |

> 你本机 F7 = quick save、F8 = quick load、F10 = 控制台，F9/F11/F12 空闲。
| 排查坐标 | 控制台 `soulcam_debug` |

## 物体菜单

右键物体打开，包含：

1. **操作轴**：进入后可拖动三轴（右键切换 移动/缩放/旋转）
2. **镜头灵敏度**：数字 0 ~ 2，默认 1，越大越灵敏
3. **镜头移动速度**：数字 0 ~ 2，默认 1，越大越快
4. **碰撞箱**：开 / 关；关闭后物体固定原地，只和玩家碰撞、不和环境碰撞
5. **不透明度**：数字 0 ~ 1，默认 1，越小越透明
6. **亮度**：数字 0 ~ 2，默认 1；小于 1 压暗，大于 1 用加法混合把模型本体再画一遍
7. **无光照**：开 / 关；开启后忽略引擎光照（全亮绘制），用于物体塞进实体变黑时
8. **还原外观**：把这只物体的透明度/亮度/无光照恢复原样

> 移动/缩放/旋转过的物体会**固定在原地**；退出灵魂出窍后，位置、透明度、亮度、碰撞状态都会保留。
> 想恢复物理：菜单里「碰撞箱」关一次再开，或 `Ctrl+Z` 撤销。控制台 `soulcam_reset` 可一次性还原全部外观与碰撞。
>
> 灵魂出窍期间用 Q 摆放的物体，会出现在**镜头准星**指向的位置，而不是人物面前。
> 物体塞进其他实体导致变黑时，打开物体菜单里的「7. 无光照」即可看见；
> 插件也会给移动中的物体加动态光（`DynamicLight`），减少整块全黑的情况。

## 机制

- **相机**：`CalcView` 独立相机，只在本插件激活时接管；未激活完全不干预
- **选择**：从相机位置做 `util.TraceLine`，命中带物理/模型的非玩家实体
- **操作轴**：与 PAC3 编辑器相同的思路——把轴端点投影到屏幕，
  鼠标 12px 内算命中；拖动用「射线 ∩ 平面」换算位移，旋转用平面内角度变化
- **缩放**：服务端 `SetModelScale` + `Activate`，碰撞体积和物理一起缩放（范围 0.1x ~ 5x）
- **撤销**：每次拖拽结束由服务端登记一个 `undo` 点

## 只做加法

- 所有文件都在 `addons/soulcam/` 内，不覆盖、不修改任何原版或第三方文件
- 只用 `hook.Add` / `concommand` / `net`，不改沙盒工具、不改 gamemode
- 所有 hook 名带 `SoulCam_` 前缀；未激活时全部直接 return，不干扰其他插件
- 卸载 = 删除 `soulcam` 文件夹，无残留配置

## 已知限制

- 仅支持**单人 / 自己开房**（服务端会拒绝对其他玩家生效）
- 旋转用欧拉角累加，极端角度下可能有万向节抖动
- 缩放后质量不变，超大模型缩得很小时碰撞可能异常（GMod 本身限制）
- 仅对实体生效，地图固体 brush 不可移动

## 排查

- `soulcam_debug`：打印相机 / 眼睛 / 本体坐标与冻结状态
- `soulcam_sensitivity 0.5`：转太快就调小，`1.5` 调大
- 进入时控制台会打印 `init view at x y z`，如果和本体坐标差很远，把那行发我
