灵魂出窍（SoulCam）操作清单
作者：dy是鹅的不是
适用：Garry's Mod 单人 / 自己开房

────────────────────────────
一、安装
────────────────────────────
1. 把 addons\soulcam 整个文件夹放到：
   ...\GarrysMod\garrysmod\addons\
2. 进地图自动加载，左下角会提示 [SoulCam] loaded
3. 控制台输入 soulcam_keys 可查看当前空闲键位

────────────────────────────
二、快捷键
────────────────────────────
F6            开启 / 关闭灵魂出窍
F9            隐藏 / 显示 UI（截图用）
              F7 被 quick save 占用，想换键：bind 键位 soulcam_ui
Z             切换「控制视角 / 控制人物」
鼠标右键      准星对准物体：打开物体菜单
鼠标中键      操作轴模式下：返回物体菜单
鼠标左键      按住操作轴拖动
ESC           退出物体操控；再按一次退出灵魂出窍
W A S D       移动镜头（控制人物时移动人物）
Shift / Alt   镜头加速 / 减速
空格 / Ctrl   镜头上升 / 下降
Ctrl+Z        撤销上一次变换
soulcam_reset 卡住时强制复原（关菜单、收鼠标、退出）
soulcam_keys  列出当前未绑定的键位

────────────────────────────
三、标准流程
────────────────────────────
1. 按 F6 进入灵魂出窍
2. 镜头飞到目标位置（可穿墙）
3. 准星对准物体 → 右键 → 打开物体菜单
4. 点「1. 操作轴」→ 右键循环 移动 / 缩放 / 旋转
5. 左键拖动对应轴调整物体；中键返回菜单
6. ESC 退出轴模式，再 ESC 退出灵魂出窍
7. 物体固定在原地，退出后不会掉落

────────────────────────────
四、物体菜单说明
────────────────────────────
1. 操作轴        移动 / 缩放 / 旋转
2. 镜头灵敏度    数字 0 ~ 2，默认 1
3. 镜头移动速度  数字 0 ~ 2，默认 1
4. 碰撞箱        开 / 关
                 关 = 固定原地，只和玩家碰撞、不和环境碰撞
5. 不透明度      数字 0 ~ 1，默认 1
6. 亮度          数字 0 ~ 2，默认 1（大于 1 提亮）
7. 无光照        开 / 关
                 物体塞进其它实体变黑时打开，忽略引擎光照
8. 还原外观      恢复透明度 / 亮度 / 无光照

────────────────────────────
五、注意事项
────────────────────────────
- 仅支持单人 / 自己开房，联机不生效
- 移动过的物体会被固定；想恢复物理：
  菜单「碰撞箱」关一次再开，或 Ctrl+Z
- 无光照物体不投射阴影
- Q 生成的物体出现在镜头准星位置，不是人物面前
- 物体完全塞进实体时可能局部发黑（引擎限制），
  打开「7. 无光照」即可看见
- 所有改动都保存在当前存档/地图中，退出灵魂出窍不会还原
